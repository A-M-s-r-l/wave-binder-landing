Quickstart

Primi passi

Configura Wave Binder, collega il backend e prova un primo flusso con nodi dipendenti.

Cos'è WaveBinder?
  • Un dependency manager per gestire relazioni dati complesse.
  • Modella i dati come nodi di un grafo con dipendenze esplicite e usa RxJS per asincronia/stato.
  • Si integra con framework frontend moderni come React, Vue e Angular.
Per dettaglio completo property nodi vai a ProtoNodes Guide. Per i metodi runtime vai a API Reference.

1) Installa libreria

Mostra esempio 
npm install /path/to/wave-binder-0.0.2.tgz

2) Configura servizio esterno (extapi.json)

Mostra esempio 
{
  "target": "http://localhost:3000/api",
  "secure": false,
  "authorization": null
}

3) Prepara protonodes.json (placeholder)

Mostra esempio 
[]

In questa fase il file resta vuoto. La valorizzazione dei nodi avviene nel percorso Integrazione ecosistema WaveBinder (wizard CLI) o nella ProtoNodes Guide.

4) Inizializza WaveBinder

Mostra esempio 
import { WaveBinder, ComplexNode } from "wave-binder";
import EXT_API_CONFIG from "./extapi.json";
import LICENSE from "./license.json";
import PROTO_NODES from "./protonodes.json";

const extApis = new Map();
extApis.set("api", EXT_API_CONFIG);

export const wb = new WaveBinder(LICENSE, PROTO_NODES, extApis, []);
wb.tangleNodes();
Importante: l'istanza wb deve essere creata in un punto del codice accessibile (es. modulo condiviso/service singleton) e poi riusata. Evita di inizializzarla dentro componenti o funzioni che possono essere rieseguite, altrimenti rischi istanze multiple e stato incoerente.
  • extApis.set("api", ...) registra il servizio richiamato da serviceName: "api".
  • La chiave usata in extApis.set("api", ...) deve combaciare esattamente con serviceName nei nodi (es. "api").
  • Se cambi la chiave (es. "backend"), devi aggiornare anche i nodi con serviceName: "backend".
  • wb.tangleNodes() collega dipendenze e avvia flusso reattivo.

Integrazione ecosistema WaveBinder

Oltre alla libreria wave-binder, puoi integrare componenti ufficiali per accelerare setup e manutenzione:

  • wavebinder-autodb-back: backend CRUD configurabile per esporre tabelle DB via API.
  • wave-binder-cli: wizard CLI per valorizzare il protonodes.json creato allo step 3 (creazione/modifica nodi guidata).
In questa pagina trovi solo la panoramica. Setup, comandi e configurazione file sono nelle guide dedicate:

wavebinder-autodb-back

Installazione, configurazione DB, esposizione tabelle e integrazione nel progetto.

wave-binder-cli

Usa il wizard per popolare il protonodes.json creato prima, aggiungendo/modificando nodi in modo guidato.

Una volta che hai definito i nodi in protonodes

Gli esempi runtime (SINGLE, MULTI, CUSTOM_FUNCTION) sono disponibili nella ProtoNodes Guide, nella sezione dedicata agli esempi pratici.
