CLI

wave-binder-cli

Guida semplice per creare e modificare il file JSON dei nodi.

Cosa fa

wbcli ti aiuta a costruire e aggiornare il file nodi senza edit manuale ripetitivo.

Repository ufficiale

GitHub: wavebinder/wavebinder-cli

Come iniziare

Installazione da package locale (.tgz)

Mostra esempio 
npm install /path/to/wave-binder-cli-0.0.2.tgz

Avvio CLI

Mostra esempio 
wbcli --help

Comandi

  • wbcli wizard: wizard guidato (consigliato per uso manuale).
  • wbcli add <nodeName> <nodeType> [-j file.json] [-f fatherNode]: crea un nodo.
  • wbcli edit <nodeName> [-t nodeType] [-j file.json]: modifica un nodo.

Flusso comando wbcli wizard

La sequenza seguente descrive cosa succede quando esegui wbcli wizard.

  1. Seleziona file target JSON (esistente o nuovo).
  2. Scegli azione: Create node (guided) oppure Edit node (guided).
  3. Conferma i prompt e salva. Poi puoi continuare sullo stesso file oppure uscire.

Father vs Dipendenza (fondamentale)

Regola veloce:
Father serve quando un nodo è parte/contenuto di un altro nodo (struttura gerarchica, es. oggetto o lista).
Se vuoi cambiare quando/da cosa si aggiorna un nodo, imposta una dipendenza (dep).

Father

  • Sposta il nodo dentro un nodo contenitore.
  • Modifica la posizione nel JSON (protos[] o proto).

Chi può essere father?

  • Solo nodi COMPLEX o LIST.
  • SINGLE e MULTI non possono essere father.
Mostra esempio 
# city viene creato come figlio di geoFilters
wbcli add city MULTI -j protonodes.json -f geoFilters

Dipendenza (dep)

  • Non cambia la posizione del nodo nel JSON.
  • Definisce da quali nodi prende valori o trigger di aggiornamento.
Mostra esempio 
# esempio concettuale:
# city dipende da region -> quando region cambia, city si aggiorna
# (configurazione dal menu dipendenze in add/edit)

Esempi essenziali

Mostra esempio 
# 1) wizard guidato
wbcli wizard

# 2) aggiunge nodo top-level
wbcli add region MULTI -j protonodes.json

# 3) modifica tipo nodo
wbcli edit region -t SINGLE -j protonodes.json

Regole importanti

  • Tipi ammessi: SINGLE, MULTI, COMPLEX, LIST.
  • Tipo SIMPLE non valido: genera errore.
  • Se non passi -j, parte la selezione interattiva del file.
  • Il file JSON viene validato prima delle operazioni.
Se sei all'inizio: usa wbcli wizard. Se sei esperto o in script: usa add/edit direttamente.
