API

WaveBinder API Reference

Metodi pubblici disponibili e linee guida d'uso per runtime e nodi.

Costruttore

Mostra esempio 
const wb = new WaveBinder(license, protoNodes, services, customFunctions);

Il costruttore inizializza runtime e bootstrap licenza in background. I nodi vengono collegati con tangleNodes().

Metodi principali WaveBinder

MetodoUsoEsempio
tangleNodes()Collega dipendenze tra nodi. Se licenza ancora pending, il tangle viene deferito in automatico.wb.tangleNodes()
getNodes()Ritorna nodi runtime.wb.getNodes()
getNodeByName(name)Ricerca nodo per nome.wb.getNodeByName("region")
getNodeByNameAndType(name, type)Ricerca nome+tipo.wb.getNodeByNameAndType("region", "MULTI")
getNodeChoicesByName(name)Scelte nodo MULTI.wb.getNodeChoicesByName("region")
getDataPool()Snapshot valori correnti.wb.getDataPool()
getNodesInfo(logDepth?)Debug stato nodi.wb.getNodesInfo(10)
addCustomFunction(fn, name)Registra custom function runtime.wb.addCustomFunction((a, b) => a + b, "sum")

Tipi nodo esportati

Il package esporta anche le classi nodo runtime: SingleNode, MultiNode, ListNode, ComplexNode.

Mostra esempio 
import { WaveBinder, ComplexNode, ListNode, MultiNode, SingleNode } from "wave-binder";

const child = wb.getNodeByName("robotBehavior");
if (child?.node?.type === "COMPLEX") {
  (child as ComplexNode).fields.forEach(field => {
    // ...
  });
}

ListNodenext(size)Ridimensiona lista dinamica.wb.getNodeByNameAndType("items", "LIST").next(3)
