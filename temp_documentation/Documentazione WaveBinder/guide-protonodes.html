ProtoNodes Guide

Riferimento completo per configurare nodi, dipendenze e caricamenti in modo corretto.

Quando usare SINGLE / MULTI / LIST / COMPLEX

TipoQuando usarloEsempio
SINGLEValore singolo (stringa, numero, boolean, oggetto semplice).qty, price, note
MULTIScelta tra opzioni (select/combobox).region, province, city
LISTCollezione dinamica di elementi ripetuti.Righe ordine, elenco contatti
COMPLEXOggetto composto da più campi.customer con nome/cognome/indirizzo

Struttura ProtoNode

PropertyTipoSignificatoQuando usarla

LoadingAction (la)

PropertySignificatoDettaglio runtime
typeTipo caricamentoUSER_SELECTION, HTTP verbs, CUSTOM_FUNCTION.
addrEndpoint relativoSupporta placeholder come {region}.
serviceNameNome servizioRisolto dalla mappa extApis.
headersHeader nodoFanno merge con header del servizio.
bodyTypeFormato bodyJSON_OBJECT o MULTI_PART_FORM_DATA.
functionNameNome custom functionNome registrato in customFunctions.

Tipi di la.type

  • USER_SELECTION: valore impostato da UI/codice.
  • GET/POST/PUT/PATCH/DELETE: valore da backend.
  • CUSTOM_FUNCTION: valore calcolato localmente.

Dipendenze (dep)

PropertySignificatoEffetto
nodeNameNodo sorgenteNodo da cui leggere il valore.
parameterNameNome parametroMapping URL/query/body/custom function.
isOptionalOpzionalitaSe false, il nodo aspetta quel valore.
onUpdateInvalidazioneSe true: emette null e poi ricalcola.
typeCanale trasportoPATH_VARIABLE, REQUEST_PARAMETER, BODY.
namingResolvingRuleRegola namingUtile in scenari annidati/lista.

Effetto pratico di onUpdate

  • onUpdate: true: al cambio dipendenza, il nodo va a null e poi ricalcola.
  • onUpdate: false: ricalcolo diretto senza passaggio a null.

Esempi runtime dopo la definizione nodi

GET con due query parametri

Mostra esempio 
{
  "name": "myTablesPaged",
  "path": "/myTablesPaged",
  "type": "SINGLE",
  "dep": [
    {
      "nodeName": "page",
      "parameterName": "page",
      "isOptional": true,
      "onUpdate": true,
      "type": "REQUEST_PARAMETER"
    },
    {
      "nodeName": "size",
      "parameterName": "size",
      "isOptional": true,
      "onUpdate": true,
      "type": "REQUEST_PARAMETER"
    }
  ],
  "la": {
    "type": "GET",
    "addr": "/mytables",
    "serviceName": "api"
  }
}

SINGLE + USER_SELECTION

Mostra esempio 
(wb.getNodeByName("qty") as any).next(3);

MULTI + GET

Mostra esempio 
const region = wb.getNodeByNameAndType("region", "MULTI") as any;
region.setSelection(0);

CUSTOM_FUNCTION

Mostra esempio 
const wb2 = new WaveBinder(LICENSE, PROTO_NODES, extApis, [
  { name: "toLabel", implementation: (v) => (v ? `Label:${v}` : null) }
]);
wb2.tangleNodes();

Custom Function: forma corretta

Mostra esempio 
// registrazione
const customFunctions = [
  { name: "toLabel", implementation: (province) => (province ? `Province:${province}` : null) }
];

// nodo
{
  "name": "provinceLabel",
  "path": "/provinceLabel",
  "type": "SINGLE",
  "dep": [
    {
      "nodeName": "province",
      "parameterName": "province",
      "isOptional": true,
      "onUpdate": true,
      "type": "BODY"
    }
  ],
  "la": {
    "type": "CUSTOM_FUNCTION",
    "functionName": "toLabel"
  }
}

Custom Function: cascata nodi con delay

Mostra esempio 
          
// Registrazione
const wb = new WaveBinder(LICENSE, PROTO_NODES, extApis, [
    {
        name: "delayCascade",
        // In chiamata custom function e possibile ricevere anche uno snapshot del nodo corrente
        implementation: (value, nodeSnapshot) => {
            if(!value) {
             return null
            }
            setTimeout(() => {
                wb.getNodeByName(nodeSnapshot.node.name).next(value);
            }, 300);
        }
    }
]);

// Avvio
wb.getNodeByName("node-0").next(value);

La libreria prova mapping per nome parametro; se non affidabile (es. minify), usa fallback per ordine dipendenze.

Best practice: allinea i nomi argomento funzione con parameterName delle dipendenze. Non è obbligatorio al 100% (esiste fallback per ordine dipendenze), ma è fortemente consigliato per evitare ambiguità in build minificate/transpiled.
